`@samline/scroll-to` scrolls smoothly to anchors, elements and positions, and stops where it should: below a fixed header, centered in a strip, or at the nearest edge. Call `autoScrollTo()` (or load the CDN script) and same-page `#id` links and `[data-scroll-to]` triggers use it.

```html
<a href="#pricing">Pricing</a> <a href="#top" data-scroll-to-back-to-top>Back to top</a>
```

## How a scroll works

1. The target is resolved: an element, an `#id`, a selector, a `'next'` or `'prev'` section, `'top'`, `'bottom'`, a position in pixels, a relative position such as `'+=400'` or a point `{ top, left }`.
2. Its destination is computed for the container (the page by default), the alignment (`block`, `inline`) and the `offset`, and clamped to what can scroll. With `when: 'needed'`, a target already in view stays where it is.
3. The scroll is animated with `duration` (or `speed`) and `easing`. The destination is measured again on every frame, so images that load on the way do not make it land in the wrong place.
4. Closed `<details>` and `hidden="until-found"` content around the target opens first.
5. The wheel, a touch, a key that scrolls, a press on the scrollbar or a new scroll on the same container stops it. Reduced motion jumps instead.
6. On arrival, links move keyboard focus to the target and push its `#id` to the URL, like a native jump. With `highlight`, the target is marked with `data-scroll-to-arrived` for a moment.
7. It ends exactly once, with a reason: `arrived`, `interrupted`, `replaced`, `cancelled` or `missing`.

`scrollTo()` returns a promise of `true` when it arrives and `false` otherwise. `onStart`, `onProgress` and `onEnd`, the `scroll-to:start` and `scroll-to:end` events, the `data-scroll-to-state` attribute and the `--scroll-to-progress` custom property follow it while it runs.

## Pieces

| Job                      | How                                                       |
| ------------------------ | --------------------------------------------------------- |
| Smooth anchor links      | `autoScrollTo()`, or the CDN script                       |
| Any element as a trigger | `data-scroll-to="#id"`, a selector or `top`               |
| Clear a fixed header     | `offset`: pixels, `%`, the header, `'auto'` or `'css'`    |
| Align                    | `block` and `inline`: `start`, `center`, `end`, `nearest` |
| Scroll a box or strip    | `container`                                               |
| Boxes inside boxes       | `container: 'auto'`                                       |
| Speed and feel           | `duration`, `speed`, `maxDuration` and `easing`           |
| Relative moves           | `'+=100%'`, `'bottom'`, `{ left: '+=100%' }`              |
| Skip when visible        | `when: 'needed'`                                          |
| Step through sections    | `data-scroll-to="next"` / `"prev"`, `sections`            |
| Reach hidden answers     | Closed `<details>` open on their own (`reveal`)           |
| From code                | `await scrollTo(target, options)`                         |
| Measure only             | `scrollPosition(target, options)`                         |
| Follow it                | `onStart`, `onProgress`, `onEnd`, or `scroll-to:*` events |
| Style it while it runs   | `[data-scroll-to-state='scrolling']`                      |
| A bar that fills with it | `--scroll-to-progress`, from `0` to `1`                   |
| Show where it landed     | `highlight` and `[data-scroll-to-arrived]`                |
| Back to top              | `backToTop(button)` or `data-scroll-to-back-to-top`       |
| Stop it from anywhere    | `signal` (an `AbortSignal`) or `cancelScroll()`           |
| Share options            | `createScrollTo(defaults)`                                |
